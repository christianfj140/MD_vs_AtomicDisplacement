Metric guide

                    

                      
Low-energy RMSE

                      
Error in the low-energy eigenvalue region; useful to compare chemically relevant bands.

                      
Fermi-window RMSE

                      
Error close to the SIESTA Fermi level; useful for frontier electronic behavior.

                      
Frontier-window RMSE

                      
HOMO/LUMO fallback when the Fermi-window metric is unavailable.

                      
Global / aligned RMSE

                      
Whole-spectrum eigenvalue error, optionally after alignment; useful to detect broad spectral drift.

                      
Gap error

                      
Absolute HOMO-LUMO gap error; useful when the band gap is the target property.

                      
Relative Frobenius

                      
Relative matrix error on the Hamiltonian; useful for overall matrix fidelity.

                      
MAE ref

                      
Mean absolute Hamiltonian error on SIESTA reference support.

                      
MSE / meV aliases

                      
Hamiltonian matrix diagnostics on the same sparse supports; MSE is eV^2 and meV aliases are unit conversions.

                      
Hamiltonian R2

                      
Complementary matrix diagnostic; higher is better and unavailable for constant targets.

                      
Support F1

                      
Overlap between predicted and reference non-zero matrix support; higher is better.

                      
DOS W1

                      
Wasserstein distance between density-of-states curves; useful for spectral-shape comparison.

                      
DOS MAE 500 Fermi window

                      
DeepH-comparable DOS diagnostic on 500 points in [-6,+6] eV around a real SIESTA Fermi level.

                      
Orbital-pair diagnostics

                      
CSV diagnostics at metrics/orbital_pair_metrics.csv; use MAE meV by species pair and local orbital indices, not as an exact DeepH H' winner metric.

                      
Time

                      
Total pipeline wall time; useful to trade accuracy against compute cost.

                    

                    

                      Cross plots reuse the selected cross metric. Lower is better except Support F1 and R2 metrics.
